Reconnect after reload

The browser closes Bluetooth when the page reloads. Tap each stick, then pick it in the list. Make sure SKZ V2 and other light stick apps are closed.

Bluetooth protocol profile

Each brand of stick listens for color commands on its own Bluetooth characteristic. The Stray Kids V2 profile is built in, decoded from the official app. Bytes are hex; {r} {g} {b} {w} are filled in live.
